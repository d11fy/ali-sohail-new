# بورتفوليو علي سهيل الكحلوت

بورتفوليو عربي تفاعلي مبني باستخدام React وTypeScript وVite وGSAP، مع أيقونات تقنية ذات عمق بصري وحركات مرتبطة بالتمرير.

## التشغيل

```bash
npm install
npm run dev
```

نسخة الإنتاج:

```bash
npm run build
npm run preview
```

## المحتوى

- معلومات علي المهنية مأخوذة من الملف الذي قدمه داخل المحادثة.
- أسماء وروابط معرض الأعمال مأخوذة من قسم المشاريع في بورتفوليوه القديم، دون نقل صوره الشخصية أو نصوص الأقسام الأخرى.
- الواجهة تعرض قصاصة شفافة من الصورة الأصلية في `public/assets/ali-cutout.png`، مع إظهار الجزء العلوي فقط. أُزيلت الخلفية دون إعادة توليد الوجه أو تعديل ملامحه.
- التصميم مستوحى من تسلسل مشاهد فيديو محمد وهبة الذي قدمه علي: واجهة بنية داكنة، بطاقات افتتاحية، أقسام بيضاء، أيقونات تقنية لامعة، وخط عربي كبير.
- عند تفعيل تقليل الحركة تتوقف التأثيرات المتحركة.

يمكن تعديل النصوص وروابط المشاريع في `src/App.tsx`.

## التأثيرات وربط المصادر

- **GSAP وScrollTrigger:** مثبتان في المشروع ويشغلان دخول الافتتاحية وحركات التمرير. أضفنا أيضًا استجابة خفيفة لحركة المؤشر على الصورة وبطاقات الافتتاحية، وتعمل على الأجهزة التي تستخدم فأرة فقط.
- **Figma MCP:** أرسل رابط ملف Figma ورابط الإطار أو الطبقة المطلوبة داخل المحادثة. يمكن قراءة التصميم والحركة عبر `get_design_context` و`get_motion_context` ثم تنفيذها في ملفات المشروع. لا يحتاج الموقع إلى تضمين Figma عند التشغيل.
- **Spline:** أنشئ مشهدًا تفاعليًا في Spline وانشره، ثم أرسل رابط `scene.splinecode`. بعدها يمكن تضمينه في قسم محدد مع نسخة ثابتة للهواتف أو الأجهزة التي لا تدعم WebGL. لا يوجد مشهد Spline مربوط الآن.
- **React Bits وMotion وCodrops:** مصادر مكونات وأفكار ومكتبات تنفيذ، وليست خدمات MCP تُربط كلها بالموقع. نختار منها عنصرًا بعينه عند الحاجة بدل تحميل مكتبات متعددة للتأثير نفسه.
- **React Bits Split Text:** أُضيف مصدر المكوّن في `src/component/SplitText.tsx` بنسخة TypeScript/CSS ويحرّك كلمات عنوان قسم «عنّي». نستخدم تقسيم الكلمات حتى تبقى حروف العربية متصلة.
